# Security policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `sudarshantechlabs@gmail.com`. Include the affected file or behavior, reproduction steps, and expected impact when possible.

Do not open a public issue for an unpatched vulnerability. Please allow time to investigate and prepare a fix before discussing the report publicly.

## Current security posture

ShyMirror is a static, zero-dependency site. It does not collect, persist, or transmit user data. It loads no third-party scripts and uses a restrictive Content Security Policy. Generated sounds use the browser's Web Audio API and begin only after user interaction.
