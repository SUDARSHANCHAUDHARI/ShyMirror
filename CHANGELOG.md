# Changelog

All notable user-facing changes to ShyMirror are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses semantic versioning.

## [Unreleased]

### Added

- Responsive interactive cartoon room with a real character, mirror, and independently animated reflection.
- Ten shuffled reflection rebellions, including hiding, drawing, turning around, leaving, and character replacement.
- Meaningful interaction tracking and a brief synchronization event after every five actions.
- Pointer, touch, keyboard, sound, reset, and reduced-motion support.
- GitHub Pages-ready static project documentation and production checks.

### Security

- Added a restrictive static-site Content Security Policy.
- Added explicit ignores for secrets, local configuration, keys, signing material, caches, and generated output.
